# 07-revflow（冲流台）

冲流台 — 正向与冲正流水净额归并：正向装载 → 冲正关联入账 → 净额归并落余额 → 未平/超额隔离 → 补正向对消补记 → 流水净额与余额互证。

**不是** 多源 Feed 归并，**不是** 作业依赖编排，**不是** CDC 变更流，**不是** 质检签发，**不是** 数仓分层建设，**不是** 交班过户。  
**也不是** 收银/退款 CRUD 后台、电商订单、报表 CSV 看板——主链是**流水管道与净额状态**，不是业务单据编辑台。

## 主链

账户登记 → 装载正向流水 → 装载冲正并关联原单 → 跑净额归并（已配平落余额，未平/超额进隔离）→ **补正向补记 + 冲正对消** → 互证报告核对「流水净额 vs 账户余额」

## 补正向与对消边

归并配平后若发现原正向装载少计，可登记一笔**补正向**补记敞口。规则：

- 必须引用一笔**已归并**冲正；无引用的普通正向不能冒充补正向（库触发器兜底）。
- 补额 > 0；补额与对消分都不得超过被引用冲正**剩余可对消额度**（冲正金额 − 已对消合计）。
- 对消关系物化为独立 **`offset_edges`** 表（补正向键、冲正键、对消分；二者择一的落库形态选独立表），
  边不可修改、不可删除（`trg_offset_edges_no_update/no_delete` 触发器兜底）；
  补正向行绑定后不可再改键/账户/金额/类型/引用冲正。
- 另落一条基线所无的只读**对消证明实体 `offset_proofs`**：证明键、补正向键、冲正键、对消分、
  冲正金额与**本次对消后冲正剩余额度快照**，同样禁止改 / 删；只读接口
  `GET /api/offset-proofs` 支持按补正向键（`forward_entry_key`）或冲正键（`reverse_entry_key`）查询。
- 登记走「同事务原子绑定」路径（两种保护路径择一，选此）：同一事务内写补正向 → 写对消边 →
  回读确认边已物化 → 写对消证明，**边 / 证明未落库绝不抬余额**；最后才按账户全量已归并流水重算余额。
  任一校验失败整笔回滚（失败闭），不留下半截补正向 / 边 / 证明 / 余额。
- 补正向不再进入冲正 FIFO：匹配层显式排除已绑定补正向，无关冲正若把补正向当原单，
  归并时一律以「冲正不得抢占补正向」隔离（另有防御性兜底，即便补正向键混入匹配字典也不参与占用）。

接口：`POST /api/compensatory-forwards`、`GET /api/compensatory-forwards`、
`GET /api/offset-edges`、`GET /api/offset-proofs`、`GET /api/compensatory-report`。
正向流水页可登记补正向并看到指向的冲正键与对消证明（含冲正剩余额度）；冲正页反向显示其补正向对消与证明；
净额互证页给出补正向笔数、对消边、对消证明（边/证明一致性）、引用冲正敞口与对余额影响，
均与流水 / 敞口 / 余额同一快照读出。


## 界面约定

页面文案全部中文；入口：总览 / 账户 / 正向流水 / 冲正流水 / 归并台 / 未平隔离 / 净额互证。
